# PlexusTerm 0.2.19

Download the update that matches your installation directly from PlexusTerm, or open the release page when you prefer to install manually.

## What changed

- **Two update actions:** the startup notice and Settings → About offer **Download** and **Visit download page** independently.
- **Matching installers:** downloads match the installed format and architecture, with system administrator authorization for Linux packages and native Windows installers.
- **Shared progress:** both entrypoints show the same download, verification, installation and error state; duplicate requests are prevented and failures can be retried.
- **Verified downloads:** official GitHub release assets are checked against their SHA-256 checksums before installation or replacement.
- **Distribution ownership:** pacman/AUR installations stay with their package manager instead of being replaced with another package format.
- **AppImage releases:** native amd64 and arm64 AppImages join the existing Linux packages and portable archives.
- **Packaging fixes:** recognize the actual `plexus-term` package name, include authorization-helper dependencies, and refresh bundled third-party license notices.
- Update messages and guidance are available in all ten application languages.

## First upgrade

Official versions before 0.2.19 still open the download page. Install 0.2.19 once using your usual installer to get the new in-app installation flow for subsequent releases.

## Installation and safety

Choose the asset matching your system. Linux downloads include `.deb`, `.rpm`, `.tar.gz` and `.AppImage` for amd64/arm64; Windows x86_64 includes MSI and NSIS installers. `checksums.txt` covers every installer/archive.

Administrator passwords are handled by the operating system, not PlexusTerm. Linux authorization requires a running desktop polkit agent. PlexusTerm does not automatically restart itself; restart manually when ready, and follow any installer instructions about closing the app.

Automatic portable updates recognize the user installation at `~/.local/bin/plexusterm`. Unknown installation locations and missing matching assets fail visibly; **Visit download page** remains available. Windows package-manager ownership is not inferred from MSI registration.
