# PlexusTerm 0.2.20

Keep the top toolbar compact even in wide windows with the new icon-only option.

## What changed

- **Icon-only toolbar:** enable **Settings → Appearance → Show only icons in the toolbar** to hide action labels.
- **Remembered preference:** the choice is saved automatically and restored when PlexusTerm opens again. Labels remain enabled by default.
- **Accessible actions:** hover tooltips, keyboard shortcuts and accessible button names remain available. Turn the option off to restore labels; narrow windows still switch to icons automatically.
- The new setting is translated into all ten application languages.

## Downloads

Choose the asset matching your system: Linux amd64/arm64 (`.deb`, `.rpm`, `.tar.gz` or `.AppImage`), or Windows x86_64 (MSI or NSIS installer). Verify downloads against `checksums.txt`.
