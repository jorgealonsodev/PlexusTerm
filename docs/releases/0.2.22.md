# PlexusTerm 0.2.22

Shell integration: local shells now tell PlexusTerm exactly where the prompt ends and how each command finished.

## What changed

- **Shell integration (OSC 133):** bash, zsh, fish, PowerShell, Git Bash and cmd mark their prompt, the command line, the command's run and its exit code, as VS Code and Windows Terminal read them. Inline suggestions, the command history and prompt detection read exactly the command line you type, also after Tab completion, arrows or Ctrl+R. Your own startup files and prompt themes keep working.
- **Autosuggestions stay out of the history:** the grey suggestion fish or zsh-autosuggestions draws after the cursor, and a right prompt, are no longer recorded as part of the command.
- **Settings → Terminal → Shell integration** (on by default) turns it off for terminals opened from then on; on Windows the shells still report their folder for the Explorer.
- **Settings search:** a box at the top of Settings finds any setting.
- **Show folder in Explorer** in a tab's right-click menu opens the Explorer (or the SFTP browser) at that terminal's folder.
- **Update notice** now shows as a floating card.
- **Emoji** are measured as two cells (Unicode 11 widths), so prompts with icons no longer shift the text after them.
- New texts are translated into all ten application languages.
