# PlexusTerm 0.2.23

Command blocks, a command palette, your own highlight rules and saved sessions synced between computers.

## What changed

- **Command blocks:** with shell integration, a command that fails gets a red dot beside its prompt; hover it for the exit code and how long it ran, and click it to open the terminal's AI chat with the command and its output attached. Ctrl+Shift+Up/Down scroll from prompt to prompt, other actions jump between failed commands only or run the last failed one again, and **Copy command output** in the terminal menu copies what one command printed.
- **Long commands:** a command that runs longer than 10 seconds (Settings → Terminal) marks its tab, and with PlexusTerm in the background shows a desktop notification, when it finishes.
- **Command palette (Ctrl+Shift+P):** one box for every action, saved session, macro, tab and settings section.
- **Command history search (Ctrl+Shift+H):** the commands run before on the focused terminal's computer, newest first; the chosen one is typed at the prompt.
- **Highlight rules:** regular expressions whose matches are coloured in every terminal, optionally notifying; one colouring IPv4 addresses comes as an example.
- **Sync sessions between computers:** choose a folder you already sync (Syncthing, Drive, Dropbox…) in Settings → Connections; the change made last wins, deletions spread, passwords never leave the computer.
- **Logs:** Log to file… starts each line with its date and time (Settings → Terminal).
- **Settings:** every option now sits in a named group, and a few moved to where they belong.
- **GPU acceleration** is on by default on Linux too, and text stays sharp with a fractional display scale.
- **AI plan usage** in the bar under the terminal is off until you choose a provider, and every window shares one read: online services are asked at most every 5 minutes.
- **Fixes:** a folder reported by a program running in the terminal (such as gentle-shell) no longer moves the Explorer; zsh keeps `ZDOTDIR` unexported when your `.zshenv` does not export it.
- New texts are translated into all ten application languages.

## Downloads

Choose the asset matching your system: Linux amd64/arm64 (`.deb`, `.rpm`, `.tar.gz` or `.AppImage`), or Windows x86_64 (MSI or NSIS installer). Verify downloads against `checksums.txt`.
