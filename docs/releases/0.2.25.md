# PlexusTerm 0.2.25

Tabs that come back at startup, SSH sessions that reconnect by themselves, settings synced between computers, and a long list of tools from other terminals: copy mode, quick select, recordings, ZMODEM, tab sets, find in all tabs, a drop-down window, proxy and password commands, and the kitty keyboard protocol.

## What changed

- **Restore tabs at startup** (Settings → General, on by default): the tabs of the last run come back with their order, split panes, sizes and colours. No passwords and no scrollback are kept.
- **SSH reconnects when the network comes back:** open SSH sessions are checked as soon as the network returns and reconnect on their own, without waiting for the connection to time out.
- **Sync settings between computers:** choose a folder for them in Settings → Connections → **Settings synced folder**, the sessions' one or another; the drop-down window's shortcut and height stay on each computer.
- **See what changed:** the update notice and Settings → About show the new release's notes before you install it.
- **Tab sets:** save the open tabs under a name ("Production", "Project X") and open them again next to the current ones from **More → Tab sets…** or the command palette.
- **Find in all tabs (Ctrl+Shift+G):** search the text of every terminal at once, see the matches grouped by tab, and jump to the one you choose. The command palette and command history now share its look: a search bar and a key hint.
- **Copy mode (Ctrl+Shift+X) and quick select (Ctrl+Shift+Q):** move a cursor over the scrollback and copy with the keyboard, as in tmux; or put a short label on every link, path, IP address, git hash and e-mail on screen and copy (or open) it by typing the label.
- **Record and play sessions:** **Record session…** saves a pane as an asciicast v2 file (output only, never what you type) and **Play recording…** plays it in a read-only player with pause, speed and seeking. The files also play in asciinema.
- **ZMODEM (rz/sz):** receive and send files inside an SSH session; PlexusTerm asks where to save them and shows the transfer's progress.
- **Drop-down window:** a global shortcut (Settings → General) brings PlexusTerm down from the top of the screen, as in Guake or Yakuake, and hides it again (X11).
- **SSH sessions:** forward your local SSH agent and keep the shell in tmux, per session. Reach a server through a **proxy command** (cloudflared, AWS SSM…); importing `~/.ssh/config` now brings `ProxyCommand` and jump hosts with a port. Take the password or key passphrase from a **password manager's command** (pass, Bitwarden, 1Password, KeePassXC with a key file…), with presets in the session dialog; the password is never saved.
- **Highlight rules and macros:** a highlight rule can now also send text or play a macro when it matches, and a macro with `{{name}}` variables asks for their values before it plays.
- **Cursor:** choose the terminal cursor's shape (block, bar or underline) and whether it blinks.
- **Shortcuts in menus:** every menu entry with a shortcut shows it beside it.
- **Kitty keyboard protocol:** programs that ask for it, such as Claude Code, now tell Ctrl+Enter, Shift+Enter and similar keys apart.
- PlexusTerm is built for Linux and Windows; the documentation no longer mentions macOS.
- New texts are translated into all ten application languages.
