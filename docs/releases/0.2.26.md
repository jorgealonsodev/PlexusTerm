# PlexusTerm 0.2.26

Paths completed as you type, an Explorer that keeps up with the terminal, text you size with Ctrl and the mouse wheel, and the plan usage of AI tools in detail, now also for Antigravity's `agy` 1.4.

## What changed

- **Path completion:** in local terminals, when your history has nothing for the line, the path at its end is completed in grey from the files of the shell's folder: `./` in a folder with one script suggests its name, and `cd n` suggests the folder starting with `n`. Accept it with Right Arrow or End, as any suggestion.
- **The Explorer follows the terminal at once:** bash, zsh and fish now report their folder at every prompt, so the Explorer moves as soon as you `cd`, without the second of delay, and it opens at the terminal's folder from the start instead of your home folder.
- **Open folder:** a new first icon in the Explorer's toolbar opens a folder chosen in the system's dialog; in DEV mode it opens it in a new DEV tab. The toolbar's icons are now grouped by what they do, and **Follow terminal** is the same chip outside DEV mode.
- **Ctrl and the mouse wheel size the text:** over a terminal it changes the terminals' font, over the AI chat the chat's text, and over the Explorer or the SFTP browser their own text size, a new setting in Settings → Appearance.
- **Plan usage in detail:** rest the pointer on the AI plan usage under a terminal to open a card with every window: a bar, the percentage, and how long until it resets.
- **Antigravity `agy` 1.4:** its plan usage shows again when `agy` is started in a PlexusTerm terminal with shell integration on; started elsewhere, the card says why.
- New texts are translated into all ten application languages.
