# PlexusTerm 0.2.27

An Explorer that shows what other programs create, and the Alt and Ctrl+Shift shortcuts of AI tools such as pi and gentle-shell working in the terminal.

## What changed

- **The Explorer keeps up with other programs:** files and folders created outside the terminal (a file manager, an editor) now appear in the Explorer's list by themselves. It reads its folder again every 3 seconds while it is on screen, and when the window gets the focus back; only a changed listing is redrawn, so nothing flickers and the selection stays. Choose the interval (1 to 30 seconds) with **Refresh the Explorer's list every** in Settings → Files.
- **Alt and Ctrl+Shift shortcuts reach AI tools:** when a tool turns on the kitty keyboard protocol, a letter, digit or symbol with Alt, Ctrl+Alt, Shift+Alt, Super or Ctrl+Shift is now sent as its own key. pi and gentle-shell read their shortcuts only this way, so Alt+A, Alt+K, Alt+G or Ctrl+Shift+A work now. AltGr and the characters a modifier makes are still typed, and shells are unchanged. PlexusTerm's own shortcuts still win; free one in Settings → Shortcuts for a tool to get it.
- New texts are translated into all ten application languages.
