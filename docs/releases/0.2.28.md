# PlexusTerm 0.2.28

DEV mode's Explorer no longer shows the workspace's added folders once you leave the workspace.

## What changed

- **Added folders stay in their workspace:** in DEV mode, going Up or Home out of the workspace's main folder used to keep listing the folders added to the workspace under the new folder, with their git dots. They now show only while the Explorer is in the main folder or below it, and come back when you return to it.

## Downloads

Choose the asset matching your system: Linux amd64/arm64 (`.deb`, `.rpm`, `.tar.gz` or `.AppImage`), or Windows x86_64 (MSI or NSIS installer). Verify downloads against `checksums.txt`.
