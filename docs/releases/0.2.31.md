# PlexusTerm 0.2.31

Ctrl with the mouse wheel sizes the text of the file viewer, and its search panel is readable on every colour scheme.

## What changed

- **File viewer text size with the wheel:** hold Ctrl and turn the mouse wheel over a file's text in the file viewer, code or Markdown, to make it bigger or smaller, as over a terminal, the AI chat or the Explorer. It is the **File viewer text size** of Settings → Appearance; the viewer's bar still follows the interface size.
- **Readable search panel in the file viewer:** the find and replace panel of the file viewer now follows the colour scheme and looks like the terminal's find bar. Before, its fields were white and its buttons grey with grey labels, hard to read on a dark scheme.

## Downloads

Choose the asset matching your system: Linux amd64/arm64 (`.deb`, `.rpm`, `.tar.gz` or `.AppImage`), or Windows x86_64 (MSI or NSIS installer). Verify downloads against `checksums.txt`.
