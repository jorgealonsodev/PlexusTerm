# PlexusTerm 0.2.33

DEV mode can keep its tabs in the usual bar, the tab column gets its own text size, the git branch follows switches made in other apps, and Windows self-updates work again for the NSIS installer.

## What changed

- **DEV mode tabs in the bar at the top:** Settings → DEV mode → **DEV mode tabs** → **In the bar at the top** keeps the tabs in the usual bar, with the DEV mode icon on each DEV tab, instead of moving them to the column at the right.
- **Text size of the DEV tab column:** Settings → Appearance → **DEV tab column text size** sizes the column's text apart from the interface, and Ctrl with the mouse wheel over the column changes it too.
- **Branch switched in another app:** a local terminal in DEV mode reads its branch every 1.5 seconds even with no AI tool running, so a branch switched in VS Code or another app shows within moments. The branch, the Explorer's repository and its git marks are also read again when the PlexusTerm window comes back to the front, and nothing is read while it is minimised.
- **Windows updates with the NSIS installer:** an installation made with the `setup.exe` installer is recognised again, so **Install update** downloads and installs the new version instead of doing nothing.
