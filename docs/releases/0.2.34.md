# PlexusTerm 0.2.34

The Explorer creates new files and folders where you are working: inside the selected folder, or from a folder's right-click menu.

## What changed

- **New file and New folder inside the selected folder:** with a folder selected, the toolbar's **New file** and **New folder** create the entry inside it; with no folder selected, in the listed folder. The new entry is selected once created, and in DEV mode the tree opens down to it.
- **Create from a folder's menu:** right-clicking a folder offers **New file** and **New folder**, created inside that folder, in DEV mode and in the plain list.

## Downloads

Choose the asset matching your system: Linux amd64/arm64 (`.deb`, `.rpm`, `.tar.gz` or `.AppImage`), or Windows x86_64 (MSI or NSIS installer). Verify downloads against `checksums.txt`.
