# Interface languages

Objective: the PlexusTerm interface in 10 languages, chosen from the system language or in Settings. Branch `feat/i18n` (stacked on `feat/ai-assist`). Delivery: ask-on-risk. Runners: Vitest (`pnpm vitest run`), `pnpm tsc --noEmit -p .`.

## Specs

- **S1 — Ten languages.** User: "Hay que ponerle mas idiomas a la app, estos en concreto: Inglés, Español, Alemán, Francés, Japonés, Portugués (de Brasil), Chino (Simplificado), Coreano, Árabe, Hindi". Locale codes: `en`, `es`, `de`, `fr`, `ja`, `pt-BR`, `zh-CN`, `ko`, `ar`, `hi`. Acceptance: every user-facing text of the React interface (toolbar, menus, sidebar, dialogs, Settings, tools, SFTP, tunnels, macros, AI chat, notices, tooltips and accessible names) is shown in the chosen language. English is the source catalogue; every other catalogue has every key (a missing key fails `tsc`).
- **S2 — Scope of this delivery.** User chose "Interfaz primero (Recomendado)": "Toda la interfaz React (menús, diálogos, ajustes, chat, avisos) en los 10 idiomas. Los mensajes de error que vienen del backend en Rust siguen en inglés y se traducen en una segunda entrega." Product names and technical terms stay as they are (SSH, SFTP, Telnet, Mosh, model ids, file paths, shell commands).
- **S3 — Choosing the language.** User: "debe cojerlo por defecto del sistema. Y si no se detecta ingles. tambien se puede seleccionar en ajustes, y un boton de default para seleccionar el del sistema o Ingles, por si te equivocas y no estinedes nada". Acceptance: default "System": the first supported language of `navigator.languages` (`pt-*` → `pt-BR`, `zh-*` → `zh-CN`), English when none is supported. Settings → Appearance → **Language** lists "System" and each language by its own name; saved in settings.json. Next to it, two rescue buttons that are never translated and apply and save at once (no Save needed): **System language** and **English**, each with a globe icon, so a user who chose a language they cannot read can get back.
- **S4 — Arabic right to left (parent proposal, not objected).** With Arabic the document is `dir="rtl"` and the interface mirrors; terminal panes, command boxes, file paths and code stay left to right. `<html lang>` follows the language.
- **S5 — Translation quality (assumption).** Translations are written by the assistant; a native review of ja, ko, ar and hi is recommended. Plurals use `Intl.PluralRules` of the language.
